# 🥃 Whisky Shop – Übungsprojekt

Dieses Projekt ist ein **Frontend-Übungsprojekt**, das im Rahmen meines Lernprozesses in **Webentwicklung (HTML & CSS)** entstanden ist.
Ziel war es, eine realistische, moderne Website für einen Whisky-Shop zu gestalten und dabei grundlegende sowie fortgeschrittene Konzepte praktisch anzuwenden.

---

## 🎯 Projektziel

* Aufbau einer strukturierten Website mit mehreren Bereichen
* Umsetzung eines ansprechenden Designs im „Whisky / Premium“-Stil
* Erste Integration von interaktiven Elementen (z. B. Modals)
* Vorbereitung auf weiterführende Technologien wie JavaScript oder Backend-Entwicklung

---

## 🧩 Features

* 🛒 Produktübersicht mit mehreren Whisky-Produkten
* 📄 Detailartige Produktdarstellung (Name, Beschreibung, Preis, Button)
* 🥃 Bereich für Whisky-Tastings inkl. Termine und Orte
* 🪟 Interaktive Modals für Zusatzinformationen (Bootstrap)
* 🔗 Navigation innerhalb der Seite (Anchor Links)
* 🎨 Einheitliches Design mit Fokus auf Lesbarkeit und Stil

---

## 🛠️ Verwendete Technologien

* **HTML5** – Struktur und Semantik der Seite
* **CSS3** – Layout, Styling und erste Responsive-Ansätze
* **Bootstrap (v5)** – für Modals und grundlegende UI-Komponenten
